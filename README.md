# CS50 SQL

Repositório criado para acompanhar meus estudos no curso **CS50's Introduction to Databases with SQL**, da Harvard University.

## Sobre

Neste repositório estão os exercícios e anotações que estou desenvolvendo durante o curso para aprender os fundamentos de **SQL e bancos de dados**.

## Conteúdos a serem estudados

* Consultas SQL
* Filtragem e ordenação de dados
* Funções de agregação
* `GROUP BY` e `HAVING`
* Subconsultas
* `JOIN`
* Chaves primárias e estrangeiras
* Relacionamentos entre tabelas
* Normalização
* `INSERT`, `UPDATE` e `DELETE`
* Views
* Índices
* Otimização de consultas
* Modelagem de bancos de dados
* SQLite
* PostgreSQL
* MySQL


## Curso

[CS50's Introduction to Databases with SQL](https://cs50.harvard.edu/sql/)
